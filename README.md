# 🌱 CompostMate
### *Turning Urban Waste into Green Gold*

CompostMate is a state-of-the-art, AI-powered ecosystem designed to revolutionize urban composting. By combining computer vision, gamified society dynamics, and high-level administrative oversight, we empower urban Indian households to lead the circular economy from their own balconies.

---

## 🚀 Key Value Pillars

### 📱 Native Mobile Experience
Built on **Capacitor**, CompostMate provides a fluid, high-performance mobile app experience. 
- **AI Vision Verification**: Instantly verify waste composition and estimate weight using Groq-powered Computer Vision.
- **QR Operations**: Seamlessly log waste by scanning building-cluster QR codes.
- **Offline Resilience**: Reliable performance optimized for high-density urban environments.

### 🛰️ Global Command Center
A dedicated, high-intelligence dashboard for regional platform monitors.
- **Intelligence Tab**: Real-time analytics on network waste trends, carbon offset metrics, and regional impact.
- **Node Registry**: Searchable master database of every user and building cluster with direct administrative controls.
- **Global Broadcast**: Instant communication protocol to reach every user in the network with critical updates.

### 🏙️ Society Ecosystem
Transforming individual action into community impact.
- **Society Maps**: Interactive, live-updating heatmaps of building-level sustainability.
- **Champion’s Hall**: Competitive leaderboards that drive engagement through healthy community rivalry.
- **Perk Matrix**: Reward systems that translate composting consistency into real-world benefits.

## 🛠️ Technology Architecture

| Layer | Technology | Role |
| :--- | :--- | :--- |
| **Core** | React 19 + Vite 8 | High-speed UI & Modular Architecture |
| **Mobile** | Capacitor 8 | Native Android & iOS Bridge |
| **Styling** | Tailwind CSS v4 | Modern, Responsive Glassmorphic Design |

## 📦 Installation & Deployment

### Web Development
```bash
# Install Dependencies
npm install

# Start Development Server
npm run dev
```

### Mobile Deployment (Android)
```bash
# 1. Build the Web Project
npm run build

# 2. Sync with Android Studio
npx cap sync android

# 3. Launch on Device
npx cap run android
```

## 🛡️ Administrative Framework
CompostMate uses a robust **Three-Tier Role System**:
1. **Resident**: Individual users logging waste and earning XP.
2. **Society Admin**: Building-level managers overseeing cluster data.
3. **Global Admin**: System-wide monitors with "God-Mode" capabilities, including user management, data wipes, and global broadcasts.

---

## 🌍 Impact Vision
Every kilogram of waste logged in CompostMate prevents roughly **0.5kg of CO2 equivalent** from entering the atmosphere. Our goal is to divert 1,000 tons of organic waste from urban landfills by 2026.
